# FinanceFuture Privacy Policy

This repository hosts the privacy policy for the FinanceFuture iOS app.

## Privacy Policy URL

Once GitHub Pages is enabled, the privacy policy will be available at:
```
https://anirudh-puvvada.github.io/finance-future-privacy/
```

## Setup Instructions

1. Create a public GitHub repository named `finance-future-privacy`
2. Push this `index.html` file to the repository
3. Enable GitHub Pages in repository settings
4. The privacy policy will be live at the URL above

## Files

- `index.html` - The privacy policy HTML file
